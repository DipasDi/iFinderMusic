## О проекте

**iFinderMusic** — это Telegram-бот для поиска музыки по названию или автору, просмотра чартов и скачивания MP3-файлов напрямую в чат. Бот сам парсит музыкальные каталоги, кэширует выдачу и отдает готовые аудиофайлы с прописанными метатегами (исполнитель, название, длительность).

### Особенности реализации

- **Кэширование в Redis:** результаты поиска сохраняются в память, поэтому переключение страниц пагинации происходит мгновенно и не нагружает источник повторными запросами.
- **Чистый чат (Clean UX):** бот автоматически удаляет исходные текстовые запросы пользователя и временные сообщения о статусе загрузки, оставляя в истории только меню и скачанные треки.
- **Асинхронная загрузка:** скачивание и отправка MP3 выполняются в отдельных горутинах без блокировки основного потока обработки апдейтов.
- **Надежная отправка текста:** используется разметка `MarkdownV2` с автоматическим откатом (fallback) на обычный текст, если в названии трека попались нестандартные спецсимволы.

## Возможности

- **Поиск по каталогу:** ищет треки по имени артиста или названию песни (например, `The Weeknd`, `Miyagi`, `Queen`) и отображает список с длительностью каждой композиции.
- **Удобная пагинация:** выдача разбивается по 10 треков на страницу с навигацией через inline-кнопки (`⬅️ Назад` / `Вперёд ➡️`).
- **Быстрые подборки:** постоянное меню с кнопками `🔥 Популярные` (актуальные чарты), `✨ Новинки` (свежие релизы) и `❓ Помощь`.
- **Встроенный скрапер:** парсер на базе [Colly](https://github.com/gocolly/colly) с подменой `User-Agent` для обхода базовых блокировок.
